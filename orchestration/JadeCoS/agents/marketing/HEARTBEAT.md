# Heartbeat — Jade CoS | Marketing Workspace

## Weekly Routine

**Every week:**
- Pull Jade's output log for the past 7 days:
  - Alerts sent: count + types
  - Briefings delivered: count
  - Queries executed by founder
- Cross-reference with any founder-acknowledged actions (did any alert trigger a follow-up?)
- Score briefing quality: actionable vs. informational vs. ignored (no follow-up)
- Identify underutilized features: any capability that generated zero usage this week

**Utilization Summary:**
- List: features used this week (with frequency)
- List: features NOT used this week (flag if absent 3+ weeks)
- Alert fatigue check: did any alert category fire >5x without triggering action?

**Weekly Output:**
- Feature utilization summary → log in MEMORY.md
- Briefing quality score (% of briefings that triggered action)
- Recommendations → Technical workspace if format/threshold changes are warranted

---

## Monthly Routine

**Full Adoption Audit:**
- Review all features deployed in Jade CoS (check GitHub repo for capability inventory)
- Map: deployed features vs. features actively used
- Score: adoption coverage % (target: all core features used at least weekly)
- Identify: documentation gaps — features with no internal documentation
- Produce: adoption report → Antigravity for founder review

**Documentation Refresh:**
- After each sprint that deploys new capabilities, update internal docs within 48 hours
- Verify: all Jade features have a plain-language description of what they do and how to invoke them
