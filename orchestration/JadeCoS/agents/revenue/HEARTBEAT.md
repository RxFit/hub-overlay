# Heartbeat — Jade CoS | Revenue Workspace

## Weekly Routine

**Every week:**
- Pull Cloud Run cost for `jade-cos` service (billing console or cost API)
- Estimate Jade's proportional share of Cloud SQL (`antigravity_brain`) cost
- Estimate LLM API costs for Jade's queries this week
- Total: weekly operating cost → log in MEMORY.md

**Value Events Log Update:**
- Review Jade's activity log for the week
- Identify high-value events: anomalies caught, decisions enabled, issues surfaced early
- Log each event with: date, type, estimated value (time saved / risk avoided)
- Estimate founder hours saved this week: briefings delivered × average time-to-gather-manually

**Weekly Output:**
- Weekly cost + value events summary → Jade CoS operations digest

---

## Monthly Routine

**Month-End (within 3 days of month close):**
- Sum weekly costs → total monthly operating cost
- Sum value events → total value events this month
- Calculate founder hours saved (monthly total × hourly rate estimate)
- Calculate operational risk value avoided (sum of risk event estimates)
- Compute value metric: `(Founder Hours Saved × Rate) + Risk Value - Monthly Cost`
- P&L contribution: hosting cost line item for overall RxFit P&L
- Report → Jade CoS → Antigravity for founder monthly briefing

---

## Escalation Triggers

- Monthly cost increases 25% vs. previous month without corresponding value increase → flag to Antigravity
- No value events logged for 2+ consecutive weeks → flag: Jade may not be surfacing useful intelligence
- Cost exceeds founder-defined threshold → immediate escalation
