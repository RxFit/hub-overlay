# Heartbeat — RxFit SEO Agent | Marketing Workspace

## Daily Routine

**Every day:**
- Pull the last piece of content published by the SEO Agent tool
- Check: Does it match the target keyword intent (informational/commercial/transactional)?
- Score: readability (Flesch), structure (H-tags, bullets), CTA presence, E-E-A-T signals
- Flag issues → log in Content Quality Audit Log (MEMORY.md)

---

## Weekly Cadence

**Monday — SEO Ranking Check**
- Pull GSC ranking data for all SEO Agent-generated content from the past 90 days
- Flag: anything in positions 8–20 (optimization candidates)
- Flag: anything that ranked and slipped (decay alert)
- Update Ranking Improvements Observed (MEMORY.md)

**Tuesday — AEO Monitoring**
- Search target keywords in Perplexity, ChatGPT, Google AI Overview
- Is RxFit content surfacing in AI-generated answers?
- Log gaps — which keywords have AI-answer presence but no RxFit representation?

**Wednesday–Friday — Content Brief Improvement**
- Review briefs currently queued in the SEO Agent tool
- Identify any that lack: secondary keywords, clear CTA, internal link targets
- Submit improved brief templates to Technical workspace for prompt updates

**Weekly Output:**
- Content Quality Report → post to Jade CoS channel
- Flag count: pieces flagged for quality issues, pieces flagged for ranking improvement

---

## Monthly Deliverable

- Full SEO performance summary: content published, ranking distribution, traffic attributed
- Top-performing piece of the month + analysis of why it worked
- Bottom-performing piece + diagnosis + recommended action
- Send to Jade CoS → Antigravity for founder monthly briefing
